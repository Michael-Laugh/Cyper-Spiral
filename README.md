# Cyper-Spiral

Cyber-Spiral, a game developed by Michael McLaughlin and Nicholas Cordial.
This game was made through the engine MonoGame, with the help of the Visual Studio 2022 IDE.
The gameplay works very simply: text will appear in the lower half of the screen, and using the story and other clues displayed will influence how you, the player, make the next choices.
The goal is to find the endings that you and the main character believe will end your "looping" condition.
Every time the player goes to the ned of a path (Ending)
the game will "restart", showing that either that was an incorrect path, or that was an ending.
